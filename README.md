# LibreNMS MikroTik Plugin

MikroTik network discovery and topology visualization plugin for LibreNMS.

## Features

- LLDP/CDP/MNDP network discovery
- Network topology visualization
- LibreNMS Device Groups integration
- MikroTik device models
- Physical interface and link monitoring
- Configurable topology settings

Under active development.
